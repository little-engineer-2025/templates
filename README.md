## Getting started

**Once tasks**

- Create a `.envrc` and customize the content:

```sh
# NOTE If you are using toolbox.sh customize
#      the name for the toolbox to use
export TOOLBOX="rust-application-dev"
export PATH="./toos:$PATH"
```

- Create a symbolic link to it: `ln -svf .envrc .env`

**Day to day tasks**

- Build by: `cargo build --release`
- Run by: `cargo run`
- Execute tests by: `cargo test`
