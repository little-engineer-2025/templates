# Templates

This repository hold templates to get started a repository for several
languages and technologies.

The idea is boostrapping the repository that you are starting and let
you focus on what you need to give a solution, instead of dealing
with over and over again with the repository initialization.

Each template holds in its own branch, letting to coexist different
templates in the same repository, and grow them independently.

Each repository try define an initial workflow for CI by defining
github and gitlab workflows; remove the workflow that you do not
need when creating your repository.

Current templates:
- **c-21-cmocka**: Starting c-21 with support for cmocka.
